# Changelog

## 0.1.0 — initial release candidate

### Added

- Session-row Delete session action and acknowledgement dialog.
- Immediate temporary deletion with a host-enforced five-second restore window.
- Bottom-right, appearance-aware restoration notice with a continuous progress animation.
- Safe disposal of captured idle agent handles, active-work guards, admission fencing and serialized mutations.
- Journaled recovery manifests, restart processing, status lookup and retryable cleanup.
- Temporary-storage host tests and simulated browser component tests.
- English/Chinese documentation, MIT license and CI checks.

### Verification status

Automated tests do not replace runtime validation in DSH. No claim of complete desktop end-to-end verification is made. Release publication and awesome-list submission are separate maintainer actions; this changelog is not proof that either has happened.
